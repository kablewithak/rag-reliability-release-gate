# North Star

Build a locally validated, public, evidence-backed RAG reliability release gate
that deliberately stresses a RAG system under context pressure, corpus drift,
dependency faults, and controlled traffic load; identifies what fails first;
proves whether a bounded intervention improves the failure; measures operational
and semantic recovery; and produces a defensible release verdict with a
remediation backlog.

## Core invariant

This project is a load-testing and chaos-engineering release gate for RAG.

It is not a generic RAG application.
